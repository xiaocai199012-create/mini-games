## 🚀 部署

纯静态HTML文件，可部署到任意静态托管服务：

- **GitHub Pages**: 免费，设置 → Pages → 选择分支
- **Vercel**: 免费，导入仓库即可
- **Netlify**: 免费，拖拽文件夹即可
- **Gitee Pages**: 国内访问快，需要实名认证
